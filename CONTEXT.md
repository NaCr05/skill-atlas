# Skill Atlas

Skill Atlas helps a person understand, select, invoke, and safely manage Agent Skills available to their local coding assistant.

## Language

**Skill Catalog**:
The trusted local collection of discovered Skills together with their readiness, provenance, and relationships.
_Avoid_: Inventory, plugin list

**Task Discovery**:
The process of matching a person’s stated task to relevant Skills in the Skill Catalog.
_Avoid_: Generic search, automatic execution

**Marketplace Candidate**:
An uninstalled Skill returned by an optional external marketplace that has not yet passed installation review.
_Avoid_: Available Skill, recommended installation

**Invocation Prompt**:
A copyable request that explicitly names a Skill and describes the work the person wants it to perform.
_Avoid_: Direct invocation, command

**Trash Record**:
A recoverable record of a personally manageable Skill that has been removed from the Skill Catalog but not permanently deleted.
_Avoid_: Deleted Skill, system recycle-bin item
